DALE Vision — Edge Agent (Windows)

EM 10 SEGUNDOS
1) Edite o .env com o token do Wizard.
2) Clique em: 01_Teste_Rapido.bat
3) Se aparecer "✅ Conectado", clique em:
   02_Iniciar_Monitoramento.bat

ALERTA DO WINDOWS (SmartScreen)
Se aparecer: "Windows protegeu seu PC"
Clique em "Mais informacoes" -> "Executar assim mesmo".

DIAGNOSTICO PARA SUPORTE
Se algo falhar, clique em:
99_Gerar_Diagnostico_para_Suporte.bat
O ZIP vai para a Area de Trabalho.

PROBLEMAS COMUNS
1) Token invalido: gere outro token no Wizard.
2) Sem internet: verifique cabo/wi-fi e tente novamente.
3) Proxy/antivirus: pode bloquear. Libere o app.
4) NVR fora da rede: conecte este PC na rede do NVR.
5) VLAN diferente: precisa de rota liberada pelo TI.

LOGS
%PROGRAMDATA%\DaleVision\logs

1) Clique em "Mais informacoes"
