# Edge Agent — Purpose & Scope

- Propósito: manter loja online e visível para a nuvem, com heartbeat e saúde das câmeras, capturar eventos e aplicar updates seguros.
- Limites: não faz decisão de negócio; não armazena longo prazo; não expõe streaming completo ao cloud; segue contratos de compatibilidade definidos.
- Compatibilidade: protocolos de heartbeat e camera health atuais devem permanecer estáveis; breaking change exige nova policy e versão major.
